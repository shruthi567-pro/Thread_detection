# Thread Detection Project

A curated collection of threat detection and hunting resources for cybersecurity professionals.

## Overview

This project contains the **Awesome Threat Detection and Hunting** repository - a comprehensive resource library for security analysts, threat hunters, and detection engineers.

## Key Categories

### 🔧 Tools & Platforms
- **Detection & Alerting**: ElastAlert, StreamAlert, Matano, Shuffle
- **Endpoint Monitoring**: osquery, Sysmon, Velociraptor, Wazuh
- **Network Monitoring**: Zeek, Suricata, Snort, Arkime
- **Threat Hunting**: HELK, DetectionLab, ThreatHunting (Splunk), Brim

### 🔍 Detection Rules
- **Sigma**: Generic signature format for SIEM systems
- **MITRE CAR**: Cyber Analytics Repository
- **Elastic Detection Rules**: Community-driven detection content
- **Splunk Security Content**: Curated detection rules

### 📊 Datasets
- **Mordor**: Pre-recorded security events from simulated attacks
- **EMBER**: PE file features benchmark dataset
- **BOTS**: Boss of the SOC datasets for training
- **PCAP-ATTACK**: Network capture samples for ATT&CK techniques

### 📘 Resources & Frameworks
- **MITRE ATT&CK**: Adversary behavior knowledge base
- **Detection Engineering**: Methodologies and best practices
- **Threat Hunting Guides**: Practical hunting techniques
- **Platform-Specific**: Windows, macOS, Linux, DNS analysis

### 🎓 Training & Labs
- **Hands-on Labs**: DetectionLab, HELK, BlueTeam Lab
- **Training Platforms**: TryHackMe, HackTheBox, Security Blue Team
- **Workshops**: SANS Summits, BSides conferences

### 🪓 Threat Simulation
- **Adversary Emulation**: MITRE CALDERA, Atomic Red Team
- **Red Team Tools**: Empire, PowerSploit, Metta
- **BAS Tools**: Infection Monkey, RedHunt-OS

## Quick Start

Explore the `awesome-threat-detection/` directory for detailed resources, or visit key tools:
- [MITRE ATT&CK](https://attack.mitre.org) - Adversary tactics framework
- [Sigma](https://github.com/SigmaHQ/sigma) - Detection rule format
- [HELK](https://github.com/Cyb3rWard0g/HELK) - Hunting ELK stack
